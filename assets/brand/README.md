# Rungs brand assets

The logo shows three ascending rungs: two waiting steps and the top one approved.

## Colors

| Name | Hex | Used for |
| --- | --- | --- |
| Background | `#0E1422` | Avatar and icon background |
| Approved | `#34D399` | Top rung |
| Mid rung | `#8A96B0` | Middle rung |
| Low rung | `#3A4560` | Bottom rung |

## Files

| File | What it is | Use it for |
| --- | --- | --- |
| `rungs-icon-rounded.svg` | App-style icon with rounded corners, vector | The README, the docs site, anywhere the logo appears inline |
| `rungs-icon-rounded-512.png` | The same icon, 512×512 PNG | Places that do not accept SVG (slides, social cards) |
| `rungs-avatar.svg` | Square avatar, vector | Source for the avatar PNGs |
| `rungs-avatar-512.png` | Square avatar, 512×512 | Profile pictures: GitHub, npm, Gravatar |
| `rungs-avatar-1024.png` | Square avatar, 1024×1024 | Where a high-resolution avatar is asked for |
| `rungs-mark.svg` | The rungs only, transparent background | On top of other backgrounds, light or dark |

Each SVG has a `<title>` ("Rungs") so screen readers announce it. Prefer the SVGs; use a PNG only
where vector images are not supported.
