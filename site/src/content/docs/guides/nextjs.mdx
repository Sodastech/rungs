complete Next.js integration: an inbox, a timeline, delegation, admin tools and a demo clock. The

## Commands in Server Actions

Each Server Action runs one command. Take the actor from the session, never from form fields,
and send back the version the form was rendered with, so that a stale form gets a conflict
message instead of overwriting someone else's decision:

<Snippet from="nextjs" file="app/actions.ts" region="decide-action" />

The example's `attempt` helper turns a `RungsError` into a message for the form and revalidates
the page. Rungs does not check permissions such as who is an administrator; check them in the
action, as the example does with `requireAdmin()`.

## Time-based work

Server Actions and pages do not run on a schedule. Run `tick` and event delivery in a separate
worker, a cron job or a scheduled route; see [Running tick](/rungs/guides/running-tick/).
