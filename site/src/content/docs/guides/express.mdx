Routes call one Rungs command each. This code runs against a real Express server in CI.

<Snippet file="guides/express.ts" region="routes" />

- **The actor comes from authentication**, here a header that stands in for your session or
  token. Never accept an `actorId` from the request body.
- **`expectedVersion`** carries the version the user saw, so a decision on stale data is refused
  ([EC-15](/rungs/edge-cases/#ec-15)).
- **`idempotencyKey`** from the `Idempotency-Key` header makes a retried POST create one request
  ([EC-16](/rungs/edge-cases/#ec-16)).

Every command method has a named input type, so the code that builds a command from an HTTP
request can be typed on its own:

<Snippet file="guides/express.ts" region="input" />

The others are `SubmitInput`, `RejectInput`, `ReturnInput`, `ResubmitInput`, `WithdrawInput`,
`DelegateInput`, `ReassignInput`, `RetryInput` and `OverrideInput`.
